# Smart Library Management System

# Project Summary 
This project is a web-based Smart Library Management System designed to make library management easier and more organized. When a student enters the library, the librarian scans the student's university ID card to automatically display their information, such as name, student ID, batch, and phone number. The library key also has its own QR code, which is scanned and linked with the student. The system records the entry and exit time, keeps track of issued books, manages book returns, and sends reminders before the return date. This helps reduce manual work and keeps all library records secure and organized.

## Technology
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: PHP
- Database: MySQL
- Server: XAMPP/Apache
- QR Scanner: html5-qrcode CDN
- IDE: VS Code

## Features
1. Admin/librarian login
2. Student registration
3. Student QR/University ID scanning
4. Library key QR scanning
5. Automatic entry/exit tracking
6. Book issue and return
7. Due-date and overdue status
8. Admin dashboard
9. Library visit logs
